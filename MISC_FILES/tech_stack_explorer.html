Rust Layer 2–4 — data ingestion · order book · risk engine
tokio
Async runtime — spawns thousands of concurrent WebSocket tasks on a thread pool. Multi-threaded scheduler maps tasks to OS threads.
tokio = "1" features = ["full"]
tokio-tungstenite
Async WebSocket client. Streams tick data from Binance, NSE, NYSE feeds. Auto-reconnects on drop — critical for HFT uptime.
tokio-tungstenite = "0.21"
serde + serde_json
Zero-copy JSON deserialization. Tick structs are deserialized directly without intermediate allocation — nanosecond parsing.
serde = "1" features = ["derive"]
crossbeam
Lock-free MPMC channels. Ingestion threads push ticks; feature engine threads pop. No mutex contention on the critical data path.
crossbeam = "0.8"
dashmap
Concurrent HashMap sharded across threads. Stores per-symbol order books, feature vectors, and live state — lock-free concurrent reads.
dashmap = "5"
ta (technical analysis)
On-tick technical indicators: RSI-14, MACD-12-26-9, Bollinger Bands-20-2, EMA, ATR. All computed in Rust — zero Python overhead.
ta = "0.5"
std::collections::BTreeMap
Sorted order book. Bids descending, asks ascending. O(log n) insert/remove. Wrapped in RwLock for concurrent multi-thread reads.
std library — zero dependency
statrs + ndarray
Statistical distributions for VaR Monte Carlo simulation. ndarray for matrix operations in the risk engine without Python overhead.
statrs = "0.16" · ndarray = "0.15"
once_cell
Lazy global singletons — FEATURE_STORE, ORDER_BOOKS. Initialized once on first access, shared across all threads without a mutex.
once_cell = "1"
reqwest
Async HTTP client for REST-based market data (Alpha Vantage, FRED). Runs in Tokio, doesn't block the tick-processing threads.
reqwest = "0.11" features = ["json"]
Bridge PyO3 + maturin — Rust ↔ Python zero-overhead membrane
PyO3
#[pyfunction] and #[pymodule] macros compile Rust functions into a Python-callable shared library. Direct memory sharing, no serialization cost.
pyo3 = "0.21" features = ["extension-module"]
maturin
Build tool. `maturin develop --release` compiles Rust with full LTO optimization and installs directly into the active virtualenv in one command.
pip install maturin

Core deep learning framework for NN1, NN3, NN4. CUDA-accelerated. autograd handles backprop. torch.compile() (PyTorch 2.0) adds 30-50% training speedup via kernel fusion.

hmmlearn == "0.3.2"

Training orchestration for all 5 NNs. Handles multi-GPU training, gradient clipping, checkpointing, early stopping, and W&B logging automatically.

PyTorch (MC Dropout)
NN4 uncertainty quantification. Dropout layers kept active at inference time. 100 forward passes → variance = model uncertainty. Higher uncertainty → smaller positions.
Built into torch.nn.Dropout
Optuna
Bayesian hyperparameter optimization for all 5 NNs. Tree-structured Parzen Estimator (TPE) efficiently searches learning rate, hidden dim, layers, dropout rate.
optuna == "3.5.0"
Weights & Biases (wandb)
Experiment tracking: logs every training run, hyperparameter set, loss curve, and validation metric. Enables comparison across model versions and ablation studies.
wandb == "0.16.0"
