Deep learning architecture novelties
Sequence models
LSTM + Multi-head attention hybrid (NN1)
Rather than vanilla LSTM, a temporal transformer attention layer attends over the 60-tick history. Captures long-range dependencies that LSTM forgets — e.g., a price pattern 45 minutes ago still influencing now.
Uncertainty
Monte Carlo Dropout (Bayesian NN4)
Dropout kept active at inference. 100 stochastic forward passes approximate a Bayesian posterior. The variance of outputs = epistemic uncertainty. High uncertainty directly reduces position sizing — a novel risk management mechanism.
Hybrid model
CNN-HMM regime detector (NN3)
1D CNN extracts local pattern features from price windows (head-and-shoulders, cup-and-handle). These features are then decoded by a 4-state Gaussian HMM — combining discriminative pattern recognition with generative state modeling. Rare combination in retail quant tools.
NLP
Domain-adapted FinBERT (NN2)
Not just raw FinBERT — fine-tuned on your specific market's news corpus using contrastive loss (positive: "stock rallied" + "bullish"; negative: "stock crashed" + "bullish"). Domain-specific fine-tuning adds ~15% accuracy over base FinBERT.
Reinforcement learning novelties
RL
PPO with multi-objective reward (NN5)
Reward = α·Sharpe + β·Calmar - γ·turnover - δ·VaR_violation. The four competing objectives force NN5 to learn risk-adjusted returns, not just raw profit. Calmar ratio (return/max_drawdown) is rarely used as RL reward in open-source systems.
RL
Regime-conditioned policy (NN3 → NN5)
NN5 receives the regime one-hot vector as part of its state. This means the policy is regime-aware — it learns a different allocation strategy for bull vs bear vs sideways markets. Effectively 4 learned policies in one network.
System architecture novelties
Systems
Rust borrow-checker enforced HFT safety
Zero-cost data race prevention on the order book. Rust's type system makes it impossible to accidentally share mutable state across ingestion threads — a bug class that has cost HFT firms millions. No runtime check, no GC pause, enforced at compile time.
Risk
Two-layer probabilistic + deterministic risk
NN4 provides probabilistic risk scores (soft limits). Rust engine enforces deterministic hard limits. Even if NN4 miscalibrates, Rust never lets position sizing exceed the hard-coded VaR threshold. Defense in depth at the architectural level.
Concurrency
Parallel inference with GIL-release
asyncio.gather() submits all 5 NNs to ThreadPoolExecutor simultaneously. PyTorch releases the GIL during CUDA kernel calls, enabling true GPU parallelism across models. All 5 NNs run in overlapping GPU time slices, not sequentially.
Validation
Walk-forward out-of-sample validation
Models are trained on data up to period T, tested on T+1 to T+3 months, then retrained with T+3 added. Sliding window across 3 years. Prevents look-ahead bias — the most common and fatal error in quant backtesting.
Data novelties
Features
L2 order book imbalance as a feature
bid_volume / (bid_volume + ask_volume) computed in Rust on every tick update. Academic research shows this is one of the strongest short-horizon price direction predictors — far more informative than closing price alone.
Alt data
Earnings call transcript NLP
SEC EDGAR provides full earnings call transcripts free. NN2 processes management tone, keyword frequency ("headwinds", "accelerating"), and linguistic hedging patterns — alpha sources that pure price models cannot see.
